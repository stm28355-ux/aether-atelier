# Aether Atelier（エーテル・アトリエ）

灯りが消えて寂れた霧の町ミストヘイヴン。魔導具の工房の新しい主として、限られた区画に機械とベルトを詰め込み、町を元に戻して、最後は飛空艇を空へ送り出す工場パズルです。熱や冷気や光の範囲が、機械だけでなくベルトを流れる素材にも効くので、ベルトの通り道がそのままレシピになります。戦闘も移動も資源探しもありません。

**遊ぶ：** https://stm28355-ux.github.io/aether-atelier/ （PC のブラウザ・マウスで遊びます。セーブはブラウザに自動で残ります）

## 中身

16区画、5つの大目標（と、おまけの区画が1つ）。区画ごとに新しい悩みが1つずつ増えます。開いた区画は見ていない間も動き続け、作った物は倉庫を通してあとの区画へ届きます。

### 第1部：機工と炉と霜

| 区画 | 作る物 | 新しい悩み |
|---|---|---|
| 区0 工房の入口 | 板 | ベルトと分岐 |
| 区1 炉の間 | 金属板・鉱石粉 | 竜炉の熱を3マス通すと鉱石が溶ける（通り道がレシピになる） |
| 区2 歯車の作業場 | 枠・歯車 | 前の区画の物を倉庫から受け取る。下をくぐるベルト |
| 区3 灯りの工房 | ガラス・レンズ | 地脈がない。魔力炉の範囲と燃料 |
| 区4 からくり工房 | ねじ・歯車箱 | 旋盤をつなげて並べると速い。区1を改善して金属板を増やす |
| 区5 霜の蔵 | 結晶・焼き入れ鋼 | 冷気。熱と冷気が重なると打ち消し合う。混ざって出る口を選り分ける |
| 区6 時計塔の基部 | 時計の機構 | 揺れる機械の近くでは、からくり台が止まる（大目標「時計塔が動く」） |
| 区7 灯台通り | 魔導ランタン | 別レシピ（大目標「町に灯りがつく」） |

### 第2部：エーテル・育てる・飛空艇

| 区画 | 作る物 | 新しい悩み |
|---|---|---|
| 区8 霧の精製所 | 精製燃料 | 副産物。精製器は精製エーテルと澱を交互に出す |
| 区9 浮き石の工房 | 浮遊石 | 時間で変わる。浮遊石の素は6秒で石くずになる（冷気の中では止まる）。速いベルト |
| 区10 浮き橋の桟橋 | 浮き板 | 水の地形。水の下は下をくぐるベルトで（大目標「浮き橋がかかる」） |
| 区11 光苔の庭 | 光る苔 | 光の範囲。胞子が光の中で苔になる |
| 区12 苗床の温室 | 光る苔 | 増える。育て床で苔を増やし、一部を戻す。優先分岐 |
| 区13 帆と糸の工房 | 帆布・苔の鉢 | 熱で乾かす苔と、乾かさない苔を分ける（大目標「温室と市場」） |
| 区14 飛空艇の部品工房 | 浮き袋・航海計器・船体 | たくさんの口から受け取る |
| 区15 天空の造船所 | 飛空艇 | 4×4の大きな機械（大目標「飛空艇が飛ぶ」） |

大目標を達成すると、町の地図の絵が変わります（時計塔の針、通りと灯台の灯り、島への浮き橋、温室と市場、空を渡る飛空艇）。

### おまけ：区16 1枚の工房

飛空艇が飛ぶと開きます。倉庫の出す口を、原料（木材・鉱石・砂・エーテル水・胞子）を選んでどこにでも・いくつでも置けるので、1枚の盤面（26×27）で原料から飛空艇まで作ります。前の区画からは何も届かず、作った物は倉庫に入りません。

## 遊び方

1. 左の「置く物」から選んで、盤面をクリックして置く。ベルトはドラッグで引く。置く物は系統ごとのタブに分かれている
2. 倉庫の「出す」口から出てくる素材を、機械に通して「納める」口へ運ぶ。機械は正面（矢印の辺）から出し、残りの3辺から受け取る
3. 右の依頼の量（毎分○個）を流し続けると達成。新しい機械や次の区画が開く
4. 区画の端の瓦礫は、あとの区画で依頼を達成すると片づき、置ける場所になる（前の区画を改善するのに使う）
5. 置いた機械をクリックするとレシピを、選り分けをクリックすると左右へ分ける素材を選べる
6. 範囲の中を何マスで何に変わるか、時間で変わる素材、魔力・相乗・揺れのきまりは、図鑑の「範囲のきまり」にある
7. 範囲を選んでコピーした図面は、回して何度でも貼れる。図面は文字列にして人に渡せる

| 操作 | キー・マウス |
|---|---|
| 置く・ベルトを引く | 左クリック・ドラッグ |
| 壊す・手放す | 右クリック／Q・Esc |
| 回す | R かホイール（置いた機械にも効く） |
| 置く物を選ぶ | 1〜9、Tab で種類を切り替え |
| スポイト | E かホイールのクリック |
| 範囲を選ぶ | Shift＋ドラッグ（C コピー・X 切り取り・Delete 消す） |
| 元に戻す・やり直す | Ctrl+Z・Ctrl+Y |
| 一時停止 | Space（倍速は右上） |

第2部の新しい仕組みだけを1つずつ試す区画は、URL に `?trial` を付けると開きます（本編とは別のセーブ）。

## 開発

```bash
npm run serve    # http://localhost:5191/
npm test         # テスト（お手本の配置で、はじめから飛空艇まで全部の依頼を通す）
npm run calc -- plate=30 dust=30   # 目標の毎分の量から、機械の台数と原料を出す
```

静的HTML＋JavaScript（ESモジュール）で、ビルドはありません。計画は [docs/plan.md](docs/plan.md)、進み具合は [Milestones](https://github.com/stm28355-ux/aether-atelier/milestones)。試作用に全部の区画を開くボタンは、URL に `?dev` を付けると出ます。絵の試し描きは [palette.html](palette.html)（素材と色）、[palette2.html](palette2.html)（第1部の機械と町の地図）、[palette3.html](palette3.html)（第2部の絵）。
