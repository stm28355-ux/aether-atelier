# Aether Atelier（エーテル・アトリエ）

魔導具の工房を、限られた区画に詰め込む工場パズル。熱や冷気の範囲が、機械だけでなくベルトを流れる素材にも効くので、ベルトの通り道がそのままレシピになる。戦闘も移動も資源探しもない。

**遊ぶ：** https://stm28355-ux.github.io/aether-atelier/

機工と炉と霜の2系統、8区画が遊べます。区0（板）・区1（竜炉で溶かす）・区2（枠と歯車）・区3（魔力炉でガラスとレンズ）・区4（旋盤の相乗でねじ、からくり台で歯車箱）・区5（冷気で結晶と焼き入れ鋼）・区6（揺れを避けて時計の機構）・区7（別レシピで魔導ランタン）。区6と区7の最後が大目標です。開いた区画は見ていない間も動き続け、作った物は倉庫を通して次の区画へ届きます。進み具合は [Milestones](https://github.com/stm28355-ux/aether-atelier/milestones)、計画は [docs/plan.md](docs/plan.md) を見てください。

## 遊び方

1. 左の「置く物」から選んで、盤面をクリックして置く。ベルトはドラッグで引く。置く物は「運ぶ・機工・炉と霜・範囲」のタブに分かれている（1〜9 で選ぶ、Tab で切り替え）
2. 倉庫の「出す」口から出てくる素材を、機械に通して「納める」口へ運ぶ
3. 右の依頼の量（毎分○個）を流し続けると達成。新しい機械や次の区画が開く
4. 区画の端の瓦礫は、倉庫の「余り」で片づけると置ける場所になる
5. 機械は正面（矢印の辺）から出し、残りの3辺から受け取る
6. 竜炉の周りの赤い範囲を3マス進んだ鉱石は、ベルトの上で溶ける
7. 下をくぐるベルトは、入口を置いてから同じ向きで前に出口を置く（間は4マスまで）。くぐっている間は範囲が効かない
8. 区3からは地脈がない。竜炉と研磨機は、燃料を入れた魔力炉の範囲（紫の点）に入れないと動かない。大きなからくり台は魔力炉2つで挟む
9. 置いた機械をクリック（何も持たないか、同じ物を持って）するとレシピを、選り分けをクリックすると左右へ分ける素材を選べる
10. 旋盤は隣り合うと速い。巻き機とプレス機の揺れ（斜めの線）の中では、からくり台が止まる
11. 熱や冷気の中を何マスで何に変わるかは、図鑑の「範囲のきまり」にまとめてある

キー：R かホイールで回す、右クリックで壊す、Q で手放す、Space で一時停止、1〜9 で置く物を選ぶ。

## 開発

```bash
npm run serve    # http://localhost:5191/
npm test         # テスト
npm run calc -- plate=30 dust=30   # 目標の毎分の量から、機械の台数と原料を出す
```

静的HTML＋JavaScript（ESモジュール）で、ビルドはありません。
